# Admin live fleet map

Admin → **Live fleet map** shows all registered vehicles, including assigned jeeps without active trips. Route and plate/driver search filters apply to markers and the vehicle list. Nearby markers are grouped; tap a group to zoom, or select a jeep to inspect its plate, driver, route, capacity, trip status and location age. Vehicles without valid coordinates remain listed but have no map marker.

`GET /api/v1/admin/fleet` provides a no-store, Admin-only snapshot. It uses bulk queries and returns operational metadata without email, password, phone or license-document fields. Active trip routes take precedence over driver assignments. Accepted driver GPS updates emit `fleet.locations.updated` to the authenticated Admin role room, including jeeps that have no active trip. Normal route/trip subscriptions and booking ownership remain unchanged.

The server retains the latest pending observation per jeep and flushes each second, or at 100 distinct pending vehicles, in chunks of at most 100. The Admin screen applies location changes together after 250 ms instead of fetching the entire dashboard per GPS update. It refreshes metadata every 20 seconds, after reconnection/resume, or after operational changes. Unknown vehicles trigger reconciliation. Older packets and slow snapshots cannot overwrite newer displayed positions. The existing operational-event bridge carries role events when emitted outside an API Socket.IO process; this change does not introduce a new multi-server Socket.IO adapter.

GPS status uses the observation timestamp when available: **Live** within 30 seconds, **Old GPS** from 31 to 120 seconds, **Offline** after 120 seconds, and **No GPS** for missing/invalid coordinates or timestamps. A clock more than 15 seconds ahead is also marked Offline. Status ages automatically even when no new events arrive. Offline markers show last known positions, not current verified positions. A disconnected live-feed banner identifies fallback polling; failed refreshes preserve previous data and display an error.

No database migration, new driver interaction or mobile build is needed for this map. Deploy the updated backend before publishing the updated Admin build. Enable `PARAGO_ENABLE_REALTIME=true` in the Admin web build for the socket fast path. The prepared `admin-release` uses configured production API URLs; the browser-tested `admin-web` uses loopback URLs. Neither was deployed by this change.

Validation evidence: [report](../artifacts/admin_live_fleet_2026-10-09/REPORT.md), [dashboard](../artifacts/admin_live_fleet_2026-10-09/index.html).
